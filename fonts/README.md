# Fonts

**Leland.otf** — the Leland music font from the MuseScore project
(https://github.com/MuseScoreFonts/Leland), copyright the MuseScore
contributors, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Redistributed here unmodified, as the
OFL permits; Copyist embeds it in the PDFs it engraves. Leland is a
SMuFL font (https://w3c.github.io/smufl/), which registers every glyph
to the staff: one em is four staff spaces, so the font drops onto
Copyist's staves at exactly four spatiums of point size.
