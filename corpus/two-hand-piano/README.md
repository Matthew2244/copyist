# Fixture: two-hand-piano

Ten bars of two-hand piano, C♯ minor, 72 BPM, 110 notes. Generated by
[`make.py`](make.py) — synthetic on purpose, so the corpus carries no private or
copyrighted material, but reproducing every pathology the real-world case shows.

| File | What it is |
|---|---|
| `make.py` | The generator. Deterministic — same seed, same bytes. |
| `clean.mid` | Recorded-to-a-click equivalent. Onsets 100% on an 8th grid. |
| `humanized.mid` | The same notes with per-note gaussian jitter, sd 12.4 ms, matching REAPER's humanize as measured. Shatters the chords. |
| `expected.musicxml` | Copyist's output. **Both inputs must produce this file byte for byte.** |

## What it exercises

- **Phantom rests** — releases 5–28% early, which a naive importer notates as
  orphan 32nd and 64th rests. 42 of them removed (DESIGN 7.3).
- **Certain hand splits** — simultaneities past an eleventh, which no single
  hand can play (DESIGN 8.2).
- **Hand versus staff** — low right-hand material that belongs on the bass staff
  regardless of which hand played it (DESIGN 8.5).
- **Pitch spelling** — chromatic passing tones in a four-sharp key, where the
  naive rule produces double sharps (DESIGN 9).
- **Chord shattering** — humanize moves notes one at a time, so a three-note
  chord arrives as three events (DESIGN 7.5.1).
- **Plugin-name resolution** — the track is named `Pianoteq 9`, with no GM
  program event, exactly as a real VST export arrives (DESIGN 10.2).
- **Dynamics and pedal** — a wide velocity range to normalize against, and CC64
  spans to turn into pedal marks.

## Invariants

1. `clean.mid` and `humanized.mid` both convert to `expected.musicxml`,
   byte-identical.
2. `expected.musicxml` round-trips through MuseScore to MIDI matching
   `clean.mid` on onset and pitch at 100%.
3. `analyze.py clean.mid` verdict: HARD QUANTIZED.
4. `analyze.py humanized.mid` verdict: QUANTIZED THEN HUMANIZED.

## Not a hand-corrected reference

`expected.musicxml` is Copyist's own output, frozen to catch regressions. It is
**not** a human engraver's notation of this material, so it locks in current
behaviour including current mistakes. See DESIGN.md O8.
